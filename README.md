## ✨ Features
 
### 🎨 Design & UI
- **Dark cyberpunk-editorial theme** with electric cyan (`#00d4ff`) accent color
- **Custom animated cursor** with a smooth lagging ring follow effect
- **CSS Grid & Flexbox** layouts throughout
- **Scroll reveal animations** — sections animate in as you scroll
- **Gradient mesh background** with geometric grid overlay on hero
- Distinctive typography — **Syne** (display) + **Space Mono** (code) + **DM Sans** (body)
### 🧭 Navigation
- **Sticky navbar** that compacts on scroll
- **Active section highlighting** — nav link updates as you scroll
- **Smooth scrolling** to all sections
- **Mobile hamburger menu** with full-screen overlay and X close button
### 🏠 Hero Section
- **Live particle network canvas** — animated with JavaScript
- Outlined glowing name text effect using `-webkit-text-stroke`
- Availability badge with pulsing dot
- Hero stats display (Semester · Languages · Curiosity)
- Download Resume & View Projects CTA buttons
### 👤 About Section
- Two-column layout — profile image + bio text
- Corner-bracket image frame with cyan accent corners
- Skill tags (BCA Student · AI Learner · Open Source)
- Detail cards for education, location, GitHub, language
### 🛠️ Skills Section
- **12 skill cards** in a responsive grid
- Color-coded icons per technology
- **Animated progress bars** that trigger on scroll
- Hover lift effect with glow shadow
- Cyan top-border reveal on hover
- "Learning" badge for in-progress skills (Python/AI)
### 💼 Projects Section
- **6 project cards** in a responsive grid
- Numbered project index style
- Technology tags per project
- GitHub link button per project
- "Coming Soon" badge for upcoming AI Assistant project
- Diagonal gradient overlay on hover
### 🎯 Goals / Timeline Section
- **Alternating timeline layout** (desktop) / single column (mobile)
- 4 career milestones: Now → Next → Goal → Dream
- Glowing marker icons with hover color-fill effect
- Inspirational quote block at the bottom
### 📷 Photography Gallery
- **CSS masonry-style grid** with `tall` and `wide` cell variants
- Smooth **image zoom** on hover (`transform: scale(1.08)`)
- Dark gradient overlay appears on hover
- *"Photography by Avirup"* caption + camera icon overlay
- Easily add photos by swapping placeholder divs with `<img>` tags
### 📬 Contact Section
- **JavaScript form validation** with live error clearing
- Name, Email, Message fields with styled error states
- Simulated submit with loading state + success message
- Contact links — Email, GitHub, LinkedIn, Instagram
- Ready to integrate with **EmailJS** or **Formspree**
### ⚙️ Extra Features
- **Scroll-to-top button** appears after scrolling 400px
- **Responsive** — works on all screen sizes (mobile, tablet, desktop)
- Custom **scrollbar** styling
- Text **selection** color themed to accent
- Footer with social links and copyright

## 🚀 Getting Started
 
### View Locally
```bash
# Clone the repo
git clone https://github.com/AvirupBasak/Portfolio-website.git
 
# Open in browser
cd Portfolio-website
# Just open index.html in your browser
# Or use Live Server in VS Code
```
 
### Customize It
1. **Profile photo** — Replace the `image-placeholder` div in About section with `<img src="your-photo.jpg" />`
2. **Resume** — Add `resume.pdf` to root folder, update `href` in the Download Resume button
3. **Gallery photos** — Create a `photos/` folder, replace placeholder divs with `<img>` tags
4. **Contact form** — Integrate [EmailJS](https://emailjs.com) or [Formspree](https://formspree.io)
5. **Social links** — Update GitHub, LinkedIn, Instagram, Email URLs in HTML
6. **Projects** — Edit project cards in the Projects section with your real projects
